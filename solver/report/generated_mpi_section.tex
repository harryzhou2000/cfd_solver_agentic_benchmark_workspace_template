Halo exchange is neighbor-scoped \texttt{Isend/Irecv} (no full-state collectives), and residual/force norms use \texttt{MPI\_Allreduce}.

In no case does the rank count change the result by an order-one amount. The np=8 wall times reflect this shared 4-core benchmark host, on which parallel speedup saturates.
