% ---- verification measurements --------------------------------------------
%
% These are MESH properties, and there are two meshes: CylinderB1 carries the two
% cylinder cases and NACA0012_H2 carries the other six.  Each geometric quantity
% therefore has exactly TWO values, not one, and every one of these figures is
% harvested from the solver's own mesh-verification line in the eight stdout.log
% files (scratch/mainverify/verif_constants.py).  An earlier version of this file
% quoted a single value per quantity, taking whichever mesh measured better; for
% the LSQ gradient that meant quoting 3.1e-13 from the cylinder while the mesh
% carrying six of the eight cases measures 1.4e-10, a factor of 455 worse.  The
% pairs below are the honest form and the WorstOf macros are what the prose
% quotes when it needs one number to cover all eight submitted runs.
