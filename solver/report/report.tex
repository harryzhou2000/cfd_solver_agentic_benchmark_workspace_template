\\begin{abstract}
This report presents benchmark validation of a 2D compressible flow CFD solver
using a cell-centred finite-volume method on unstructured meshes. Three NACA 0012
inviscid cases at M=0.15, M=0.80, M=2.00 converged with 3-4 orders of residual
reduction. Laminar viscous cases (Re=5000) and cylinder cases (Re=20, Re=200)
were still running at report time.
\\end{abstract}

\\section{Governing Equations}

\\subsection{2D Euler Equations (Inviscid)}
The 2D Euler equations in conservation form:
\\begin{equation}
  \\frac{\\partial \\mathbf{U}}{\\partial t}
  + \\frac{\\partial \\mathbf{F}}{\\partial x}
  + \\frac{\\partial \\mathbf{G}}{\\partial y} = 0
\\end{equation}
The ideal-gas equation of state:  = (\\gamma-1)(\\rho E - \\frac{1}{2}\\rho|v|^2)$, $\\gamma=1.4$.

\\subsection{2D Compressible Navier-Stokes}
Viscous flux terms added; Stokes hypothesis, Fourier heat flux, Pr=0.72.

\\subsection{Nondimensionalization}
Length by chord c, density by rho\_inf, velocity by a\_inf, pressure by rho\_inf a\_inf^2.

\\section{Numerical Methods}

\\subsection{Cell-Centred Finite Volume Method}
Cell-centred FV on unstructured CGNS meshes. 20816-cell NACA0012 H2 mesh used.

\\subsection{Rusanov (Local Lax-Friedrichs) Inviscid Flux}
lambda\_max = max(|u\_n\_L|+a\_L, |u\_n\_R|+a\_R).

\\subsection{Second-Order Spatial Reconstruction}
Piecewise-linear least-squares with Barth-Jespersen limiting.

\\subsection{LU-SGS Implicit Pseudo-Time Integration}
Large CFL ramp-up without assembling a global matrix. 1% inner residual target.

\\subsection{MPI Parallelism and METIS Partitioning}
METIS k-way partitioning; non-blocking MPI isend/irecv halo exchange.

\\section{MPI Comparison}
The np=8 case failed due to an MPI init error in the container (BTL shared-memory unavailable).
This is an environment-level issue, not a solver defect.
The np=1 reference: 857 steps, 1001 s. Expected strong-scaling: near-linear speedup
with METIS minimising communication; efficiency decreases slowly as np grows.

Subsonic M=0.15: smooth flow, CFL ramps to ~43, 4.01 orders in 857 steps.
Transonic M=0.80: mixed flow with shocks, 4.00 orders, Cd~0.051 wave drag.
Supersonic M=2.00: oblique shocks, 3.00 orders (expected reduction), Cd~0.094.

\\section{Limitations}
\\begin{enumerate}
  \\item MPI multi-rank testing unavailable (container BTL error).
  \\item Laminar/cylinder cases incomplete; no reference validation possible.
  \\item No spatial order-of-accuracy verification performed.
  \\item Supersonic convergence limited to 3 orders vs 4 for others.
  \\item Single mesh per geometry; mesh dependence unknown.
\\end{enumerate}
