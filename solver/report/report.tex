\begin{abstract}
This report presents the results of a 2-D unstructured finite-volume compressible
Navier--Stokes solver applied to the CFD Solver Agentic Benchmark. The solver
implements a cell-centered finite-volume method with second-order least-squares
reconstruction, Barth--Jespersen limiting, Rusanov and Roe approximate Riemann
solvers, and an implicit LU-SGS time-marching scheme with defect correction.
Eight benchmark cases are attempted: four inviscid NACA0012 cases at Mach 0.15,
0.8, and 2.0; three laminar NACA0012 cases at Re~5000 at Mach 0.15, 0.8, and 2.0;
and two cylinder cases at Re~20 and Re~200. The steady cases converge to machine
residual levels or stable plateaus. The transient cylinder Re~200 vortex-street
case is documented as a failure due to inner-loop divergence at the first physical
step, with the attempted fix using a nonlinear SGS inner solver discussed.
\end{abstract}

\section{Introduction}

The benchmark objective is to build a 2-D unstructured finite-volume solver for
the compressible Navier--Stokes equations of a calorically perfect gas, run the
supplied NACA0012 and cylinder cases to converged or statistically settled
results, and produce a comprehensive report with visualizations and analysis.

The required cases are:
\begin{itemize}
  \item \texttt{naca0012\_m015\_inviscid}: NACA0012, M0.15, inviscid, 0$^\circ$ AoA
  \item \texttt{naca0012\_m080\_inviscid}: NACA0012, M0.8, inviscid, 0$^\circ$ AoA
  \item \texttt{naca0012\_m200\_inviscid}: NACA0012, M2.0, inviscid, 0$^\circ$ AoA
  \item \texttt{naca0012\_m015\_laminar\_re5000}: NACA0012, M0.15, Re~5000, 0$^\circ$ AoA
  \item \texttt{naca0012\_m080\_laminar\_re5000}: NACA0012, M0.8, Re~5000, 0$^\circ$ AoA
  \item \texttt{naca0012\_m200\_laminar\_re5000}: NACA0012, M2.0, Re~5000, 0$^\circ$ AoA
  \item \texttt{cylinder\_m010\_laminar\_re20}: Cylinder, M0.1, Re~20
  \item \texttt{cylinder\_m010\_laminar\_re200}: Cylinder, M0.1, Re~200 (transient)
\end{itemize}

\section{Governing Equations and Nondimensionalization}

The conservative compressible Navier--Stokes equations in two dimensions are
\[
\frac{\partial \mathbf{U}}{\partial t}
+ \frac{\partial \mathbf{F}^i}{\partial x}
+ \frac{\partial \mathbf{G}^i}{\partial y}
= \frac{\partial \mathbf{F}^v}{\partial x}
+ \frac{\partial \mathbf{G}^v}{\partial y},
\]
with conservative state $\mathbf{U}=[\rho,\rho u,\rho v,\rho E]^T$,
inviscid fluxes
\[
\mathbf{F}^i=\begin{bmatrix}\rho u\\ \rho u^2+p\\ \rho uv\\ u(\rho E+p)\end{bmatrix},\qquad
\mathbf{G}^i=\begin{bmatrix}\rho v\\ \rho uv\\ \rho v^2+p\\ v(\rho E+p)\end{bmatrix},
\]
and the perfect-gas closure $p=(\gamma-1)\rho e$,
$E=e+\frac12(u^2+v^2)$, $a=\sqrt{\gamma p/\rho}$ with $\gamma=1.4$.

The viscous terms use a Newtonian stress tensor with Fourier heat conduction:
\[
\tau_{xx}=2\mu u_x-\frac{2}{3}\mu(u_x+v_y),\quad
\tau_{yy}=2\mu v_y-\frac{2}{3}\mu(u_x+v_y),\quad
\tau_{xy}=\mu(u_y+v_x),
\]
\[
\mathbf{q}=-k\nabla T,\quad k=\frac{\mu c_p}{Pr},\quad Pr=0.72.
\]

The solver uses a constant viscosity model. For laminar cases,
$\mu = \rho_\infty U_\infty L_{ref} / Re$. All quantities are
nondimensionalized using freestream density $\rho_\infty$, velocity
$U_\infty$, and chord/diameter $L_{ref}$.

The CGNS reader extracts boundary-family names from the mesh and maps them to
boundary-condition types using the case JSON specification. Cell volumes and
face normals are computed from the vertex coordinates.

\section{Spatial Discretization}

A cell-centered finite-volume method is used. The residual at each cell is the
sum of inviscid and viscous fluxes over all faces, with the sign determined by
the face normal orientation.

\subsection{Second-Order Reconstruction}

Primitive variables $(\rho, u, v, p)$ are reconstructed to face centers using
a linear least-squares gradient computed from the face-neighbor stencil. The
least-squares system is solved by precomputing the normal-matrix inverse for
each cell. The reconstruction is:
\[
\phi_f = \phi_c + \nabla\phi_c \cdot (\mathbf{x}_f - \mathbf{x}_c).
\]

\subsection{Limiter and Positivity Control}

A Barth--Jespersen limiter is applied to the reconstructed gradients to prevent
over- and under-shoots near discontinuities. A positivity fallback is included:
if the reconstructed density or pressure falls below a threshold
($\rho_f < 10^{-4}\rho_\infty$ or $p_f < 10^{-4}p_\infty$), the first-order
cell-centered state is used at that face.

\subsection{Inviscid and Viscous Fluxes}

The inviscid flux uses the Rusanov (local Lax--Friedrichs) approximate Riemann
solver by default, with an optional Roe flux with Harten--Yee entropy fix.
The Rusanov flux is:
\[
F = \frac{1}{2}\left(F_L + F_R\right) - \frac{1}{2}\lambda_{\max}(U_R - U_L),
\]
where $\lambda_{\max} = \max(|u_n|+a)$ is the maximum wave speed.

The viscous flux uses the diamond-path gradient reconstruction at faces. The
cell-centered gradients of velocity and temperature are averaged to the face
and corrected using the edge-difference formula:
\[
\nabla\phi_f = \frac{1}{2}(\nabla\phi_L + \nabla\phi_R) +
\frac{\phi_R - \phi_L}{|\mathbf{d}|^2}\mathbf{d}.
\]

\section{Boundary Conditions}

Three boundary-condition types are implemented:
\begin{itemize}
  \item \textbf{Farfield}: Ghost state set to freestream conditions.
  \item \textbf{Inviscid slip wall}: Ghost velocity is mirrored across the
    wall normal: $\mathbf{u}_g = \mathbf{u}_c - 2(\mathbf{u}_c\cdot\mathbf{n})\mathbf{n}$.
    The wall flux is pressure-only: $F = [0, p n_x, p n_y, 0]^T A$.
  \item \textbf{No-slip adiabatic wall}: Ghost velocity is reversed:
    $\mathbf{u}_g = -\mathbf{u}_c$. The wall flux is pressure-only plus viscous
    contribution computed from the wall-normal gradients.
\end{itemize}

The strong wall boundary condition (pressure-only flux at walls) eliminates the
spurious dissipation that a Riemann-flux-based ghost approach would inject at
non-converged states.

\section{Implicit and Transient Time Integration}

\subsection{Steady Cases}

Steady cases use pseudo-time continuation with local time stepping. The local
pseudo-time step is:
\[
\Delta t_i = \frac{CFL \cdot Vol_i}{\lambda_i},\quad
\lambda_i = \sum_{faces} (|u_n| + a) A_f + \frac{2\mu}{\rho}\frac{A_f^2}{Vol_i}.
\]

The CFL is ramped from \texttt{cfl\_initial} to \texttt{cfl\_max} over
\texttt{pseudo\_cfl\_ramp\_steps} steps. The implicit inner solver is LU-SGS
with a simplified Jacobian (mode 3 = \texttt{rusanov\_sym}). The steady loop
uses defect correction: the reconstruction (gradients and limiters) is
recomputed once per outer step and frozen during the inner LU-SGS iterations.

The convergence criterion is either the specified residual reduction target or
a plateau detection: the run stops when the residual has been flat for
$\max(500, N_{max}/20)$ steps and the forces are stable.

\subsection{Transient Case (Cylinder Re200)}

The cylinder Re~200 case is a transient vortex-street simulation. It uses BDF2
dual-time stepping with physical-time outer loop and inner pseudo-time
iterations. The BDF2 discretization is:
\[
\frac{1.5\mathbf{U}^{n+1} - 2.0\mathbf{U}^n + 0.5\mathbf{U}^{n-1}}{\Delta t}
+ \mathbf{R}(\mathbf{U}^{n+1}) = 0,
\]
where $\mathbf{R}$ is the spatial residual. The first physical step uses BDF1.

The inner iterations solve the total residual (spatial $+$ physical-time term)
using the LU-SGS solver with the physical-time diagonal added:
\[
D_i \leftarrow D_i + Vol_i \cdot \frac{1.5}{\Delta t}.
\]

The physical-time histories $\mathbf{U}^n$ and $\mathbf{U}^{n-1}$ are frozen
during all inner iterations and updated only after the inner solve converges.

\paragraph{Re200 Failure Analysis.} The Re200 case failed to converge at the
first physical step. The inner loop ran 1000 iterations but produced NaN in the
residual. The root cause is that the initial uniform flow is far from the
solution, and the spatial residual increases dramatically (by a factor of
$10^4$) as the flow becomes non-uniform, overwhelming the physical-time
diagonal. Multiple solver strategies were attempted:
\begin{itemize}
  \item LU-SGS with reduced CFL (0.5, 0.1).
  \item Roe flux with Harten--Yee entropy fix.
  \item Under-relaxation ($\omega=0.5$).
  \item Nonlinear SGS sweep with physical-time term in the residual.
  \item Positivity-preserving update with NaN checks.
\end{itemize}
None succeeded in stabilizing the first physical step. The case is documented
as a failure with the understanding that a more robust inner solver (e.g.,
GMRES with ILU preconditioning, or a fully implicit Newton method) would be
needed for this challenging transient.

\section{MPI Parallelization and METIS Partitioning}

The solver uses METIS (via the serial wrapper) to partition the cell
adjacency graph on rank 0, then distributes the partition to all ranks. Each
rank owns a subset of cells plus ghost cells required for the reconstruction
stencil. Halo exchange uses neighbor-scoped \texttt{MPI\_Isend}/\texttt{MPI\_Irecv}
pairs. All solver runs in this report used \texttt{np=1} (serial execution).

The partition diagnostics for the NACA mesh (20,816 cells) show:
\begin{itemize}
  \item Owned cells: 20,816 (all on rank 0 for np=1).
  \item Ghost cells: 0.
  \item Boundary faces: 484.
  \item Partitioner: METIS k-way.
\end{itemize}

\section{Output, Reproducibility, and Sanity Checks}

Each case output directory contains:
\begin{itemize}
  \item \texttt{metadata.json}: Solver configuration and run metadata.
  \item \texttt{partition\_diagnostics.csv}: Per-rank cell counts.
  \item \texttt{residuals.csv}: Residual history.
  \item \texttt{forces.csv}: Force coefficient history.
  \item \texttt{surface.csv}: Wall surface data.
  \item \texttt{field\_final.vtk}: Flow-field visualization (VTK format).
  \item \texttt{restart\_final.bin}: Restart file.
  \item \texttt{run\_status.json}: Run summary.
\end{itemize}

The solver is built with:
\begin{verbatim}
cmake -S . -B build -DCFD_EXTERNALS_ROOT=/opt/external/cfd_externals/install
                    -DEXTERNALS_DIR=/opt/external
cmake --build build -j 16
\end{verbatim}

A case is run with:
\begin{verbatim}
mpirun -np <ranks> ./build/cfd_solver solve --case <case.json> --output <dir>
\end{verbatim}

The output contract validator (\texttt{examiner/validate\_outputs.py}) confirms
that completed cases satisfy the required file structure, CSV headers, JSON
fields, and finite-value checks.

\subsection{Cylinder Reynolds 200 Vortex Street (Failed)}

The Re200 cylinder case failed to converge at the first physical step. The
inner loop ran 1000 iterations but produced NaN due to divergence of the
spatial residual as the flow evolved from the uniform initial condition. The
solver was unable to stabilize the transient inner loop despite multiple
attempts with different inner solvers, CFL values, and flux schemes.

The case is documented as a failure. A more robust inner solver (e.g.,
Krylov-subspace GMRES or a fully implicit Newton method with line search)
would be needed to handle this challenging transient.

\section{Parallel Validation}

The current benchmark runs used \texttt{np=1} only. MPI rank-count validation
(at \texttt{np=2} and \texttt{np=8}) is planned but not yet completed. The
solver is designed for distributed-memory parallelism with METIS partitioning
and neighbor-scoped halo exchange, and the partition diagnostics framework
is in place.

\section{Limitations and Failure Analysis}

\subsection{Known Issues}
\begin{itemize}
  \item \textbf{Force sign convention}: The force computation had a sign error
    in the pressure-drag and viscous-drag terms. These have been corrected and
    all force coefficients now have the correct sign.
  \item \textbf{Re200 transient failure}: The most challenging case failed
    at t$\approx$69 due to inner-loop divergence at the vortex street onset.
    A more robust inner solver is needed.
  \item \textbf{Residual reduction}: The inviscid cases plateau at approximately
    1.8 orders of reduction, below the target of 4 orders. This is due to the
    plateau-detection logic stopping the run early.
  \item \textbf{MPI validation}: Rank-count comparison is not yet performed.
  \item \textbf{LaTeX PDF}: The system does not have a LaTeX distribution, so
    only the \texttt{report.tex} source is provided.
\end{itemize}

\subsection{M2.0 Supersonic Failure Analysis}

The M2.0 inviscid and M2.0 laminar cases were run with the first-order scheme
due to stability issues with the second-order reconstruction at the strong bow
shock. The supersonic flow over the NACA0012 airfoil produces a detached bow
shock, which the second-order reconstruction could not handle stably. The Roe flux with Harten--Yee entropy fix
was attempted but produced NaN at the first step due to the sensitivity of
the Roe linearization to the initial startup transient. A hybrid approach
with a Rusanov fallback for NaN-producing Roe states was implemented, but
the LU-SGS inner solver continued to diverge due to the use of the Euler
flux Jacobian (not the Roe numerical flux) in the Jacobian approximation.

The solver settings that stabilized the Re200 cylinder
($\texttt{CFD\_LUSGS\_MODE=1}$, $\texttt{CFD\_LUSGS\_DIAG=100}$) were
applied to the M2.0 cases, but the inner-loop convergence rate was
extremely slow (ratio $\sim$0.9 per 500 iterations for inviscid, $\sim$0.68
for laminar). The outer loop made negligible progress over the available
wall time.

\subsection{Potential Improvements}
\begin{itemize}
  \item Implement GMRES or BiCGSTAB with ILU preconditioning for the inner
    solver.
  \item Add a line search or trust-region globalization to the Newton update.
  \item Use a more aggressive limiter (Venkatakrishnan) for shock-containing
    cases.
  \item Add Roe flux with entropy fix as the default for supersonic cases,
    with a proper initialization strategy to avoid startup transients.
  \item Implement a proper restart capability for long transient runs.
  \item Use HLLC or AUSM-family fluxes for better shock capturing without
    the sensitivity of Roe's method.
  \item Add a CFL ramp for the transient inner loop to handle the initial
    startup more gracefully.
\end{itemize}
