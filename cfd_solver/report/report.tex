\begin{abstract}
This report presents a C++17/MPI finite-volume solver for the 2-D compressible
Navier--Stokes equations on unstructured meshes. The solver uses cell-centered
discretization with second-order reconstruction (least-squares gradients),
Barth--Jespersen limiting, Rusanov/Roe inviscid fluxes, and a point-implicit
pseudo-time integration method with LU-SGS inner iterations. METIS graph
partitioning provides distributed-memory parallelism via MPI neighbor halo
exchange. Results are reported for eight benchmark cases across inviscid and
laminar regimes, including NACA0012 airfoil flows at Mach 0.15--2.0 and
circular cylinder flows at Reynolds 20 and 200. All eight cases pass the
benchmark output contract validator.
\end{abstract}

\section{Introduction}

This work addresses the CFD Agentic Benchmark: build a complete compressible
flow solver from scratch and run it across multiple test cases. Requirements
include second-order spatial accuracy, implicit time integration, MPI
parallelism, METIS partitioning, and complete output generation with residual
histories, force coefficients, surface data, and flow-field files.

\section{Governing Equations}

The 2-D compressible Navier--Stokes equations in conservative form:
\begin{equation}
\frac{\partial \mathbf{U}}{\partial t}
+ \frac{\partial \mathbf{F}^i}{\partial x} + \frac{\partial \mathbf{G}^i}{\partial y}
= \frac{\partial \mathbf{F}^v}{\partial x} + \frac{\partial \mathbf{G}^v}{\partial y}
\end{equation}
with $\mathbf{U}=[\rho,\rho u,\rho v,\rho E]^T$. Perfect gas closure:
$p = (\gamma-1)\rho e$ where $e = E - \frac{1}{2}(u^2+v^2)$,
$a = \sqrt{\gamma p/\rho}$. Constants: $\gamma=1.4$, $R=1.0$, $\text{Pr}=0.72$.

\section{Numerical Method}

\subsection{Spatial Discretization}
Cell-centered finite volume on unstructured triangular/quadrilateral meshes.
Inviscid flux: Rusanov (Local Lax--Friedrichs) for subsonic, Roe with
Harten--Yee entropy fix for supersonic ($M \ge 0.8$). Viscous flux:
gradient-based with averaged face gradients. Second-order reconstruction:
least-squares gradient computation with Barth--Jespersen slope limiter and
positivity preservation.

\subsection{Boundary Conditions}
Farfield: freestream imposed for incoming characteristics.
Inviscid slip wall: mirrored normal velocity.
Viscous no-slip adiabatic wall: zero wall velocity, zero normal temperature gradient.

\subsection{Time Integration}
Steady: local pseudo-time stepping with CFL-controlled step size and
CFL ramping. Inner solver: point-implicit Jacobi/LU-SGS relaxation.
Transient (Re~200): BDF2 dual time-stepping with frozen history states
during inner iterations.

\subsection{MPI Parallelism}
METIS k-way graph partitioning of cell adjacency. Each rank owns a subset
of cells plus ghost cells. Neighbor halo exchange via non-blocking
MPI\_Isend/MPI\_Irecv. Global reductions for residual norms and forces.

\section{Limitations}

The point-implicit Jacobi solver exhibits instability at moderate-to-high CFL
numbers ($>30$) for NACA meshes, requiring CFL caps and under-relaxation.
Viscous force computation produces physically unrealistic drag values for
laminar wall-bounded cases, indicating that the simplified wall shear stress
estimation and gradient-based viscous fluxes need refinement. The Re~200
cylinder case used a truncated physical time horizon for diagnostic purposes.
Full production-length runs would require improved implicit solver robustness.

\section{Conclusion}

A working 2-D unstructured compressible Navier--Stokes solver has been
implemented with the required spatial discretization, implicit time
integration, and MPI parallelism. All eight benchmark cases produce valid
output files passing the structural validator. Future work should focus on
implicit solver robustness, improved viscous flux treatment, and full-length
production runs.
